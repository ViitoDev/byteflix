# ByteFlix

Projeto de estudo em Java que simula funcionalidades básicas de uma plataforma de streaming de filmes, construído aula a aula enquanto aprendo os fundamentos da linguagem.

## Funcionalidades

- **`Main`** — exibe as informações de um filme (título, ano, sinopse) e calcula a média das avaliações.
- **`Conditional`** — verifica se o usuário tem acesso ao filme de acordo com o plano contratado.
- **`Reading`** — lê avaliações digitadas pelo usuário e calcula a média.

## Como executar

Requer JDK 17 ou superior (o projeto usa text blocks).

```bash
javac -d out src/byteflix/*.java
java -cp out byteflix.Main
```
